# Public Release Notice

This repository is a public research release.

To avoid redistributing project-specific Unreal Engine content or potentially copyrighted scene assets, the repository intentionally excludes:

- the original Unreal Engine project files,
- original scene layouts,
- original private material assets,
- project-specific meshes, UI assets, and maps,
- any copyrighted visual content not suitable for open redistribution.

What is included instead:

- a simplified Unreal Engine listener template,
- generic asset naming examples,
- Python-side orchestration and analysis scripts,
- a minimal reproduction path for the generation-to-display workflow.
