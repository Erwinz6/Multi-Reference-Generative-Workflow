# Environment Setup

Recommended baseline environment:

- Windows 10/11
- Python 3.10+
- Unreal Engine 5 with Python enabled
- ComfyUI running locally
- MCP-compatible Python environment

Before running the repository, verify that:

- Python is available in the shell,
- ComfyUI is accessible at the configured address,
- Unreal Engine editor-side Python execution is enabled,
- the workflow JSON and required custom nodes are installed.
