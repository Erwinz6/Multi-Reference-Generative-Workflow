# Contributing

Thank you for your interest in improving this repository.

## Before You Contribute

Please make sure:

- your changes do not introduce private datasets or copyrighted Unreal Engine assets,
- your changes keep the public repository reproducible,
- any environment-specific paths are documented clearly,
- third-party licenses remain respected.

## Suggested Contribution Scope

Good contribution areas include:

- documentation improvement,
- configuration externalization,
- bug fixes in orchestration or analysis scripts,
- public-safe Unreal Engine template improvements,
- reproducibility fixes.
