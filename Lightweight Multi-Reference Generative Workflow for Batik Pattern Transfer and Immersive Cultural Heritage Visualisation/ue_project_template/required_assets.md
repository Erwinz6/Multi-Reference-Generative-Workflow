# Required UE Assets

At minimum, the Unreal Engine side should provide:

- a public-safe demo material instance such as `MI_PublicDemo_Display`,
- a texture parameter such as `GeneratedTexture`,
- a target mesh or display surface using that material instance,
- Python execution enabled inside the Unreal Engine editor.

This repository does not bundle the original Unreal Engine project package or any project-specific copyrighted assets.
Instead, it documents the minimum public-safe assets required to reproduce the automatic material update workflow.
